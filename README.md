# MD Khider International Market

لوحة متابعة أسعار **الذهب** و**الفضة** و**النفط** (WTI و Brent) مع إشارات توقع فنية بسيطة.

## المتطلبات

- Python 3.9 أو أحدث
- اتصال بالإنترنت (لجلب الأسعار من Yahoo Finance)

## التثبيت والتشغيل (على حاسوبك)

```bash
# 1. انتقل إلى المجلد
cd md_khider_market

# 2. ثبّت المكتبات (مرة واحدة فقط)
pip install -r requirements.txt

# 3. شغّل البرنامج
python app.py
```

بعد التشغيل ستظهر رسائل مثل:

```
✅ الخادم يعمل على المنفذ 8080
📱 من الهاتف (نفس الشبكة):  http://192.168.x.x:8080
💻 من الحاسوب:             http://127.0.0.1:8080
```

## الوصول من الهاتف

1. تأكد أن الهاتف والحاسوب على **نفس شبكة الواي فاي**.
2. افتح المتصفح في الهاتف واكتب العنوان الذي يظهر في الطرفية (مثل `http://192.168.1.10:8080`).
3. إذا لم يعمل، تأكد أن جدار الحماية في ويندوز يسمح بالمنفذ 8080، أو جرّب إيقاف الجدار مؤقتاً للاختبار.

## الميزات

- أسعار حية تقريبية للذهب (GC=F)، الفضة (SI=F)، نفط WTI و Brent
- نسبة التغير اليومي
- أعلى/أدنى خلال 3 أشهر
- إشارة توقع فنية (RSI + المتوسطات المتحركة MA20/MA50)
- رسوم بيانية لآخر 30 يوم
- تحديث تلقائي كل دقيقتين + زر تحديث يدوي
- تصميم متجاوب يعمل على الحاسوب والهاتف
- واجهة عربية بالكامل

## ملاحظات مهمة

- البيانات من Yahoo Finance وقد تكون متأخرة بضع دقائق.
- الإشارات **ليست نصيحة استثمارية**، بل تحليل فني بسيط للأغراض التعليمية والشخصية فقط.
- للاستخدام الشخصي فقط.
